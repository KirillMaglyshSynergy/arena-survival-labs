# Arena Survival

Учебная 3D-арена для лабораторной работы 1

Маглыш Кирилл Андреевич, VДБИ-301рки

## Версии

- Unity Editor 6000.3.11f1, ветка Unity 6.3 LTS
- Universal Render Pipeline 17.3.0
- Input System 1.19.0

Версии выбраны для этой работы самостоятельно и закреплены в файлах проекта

## Запуск

Открыть папку проекта в указанной версии Unity, дождаться импорта пакетов
Открыть Assets/_Project/Scenes/Arena_01.unity и нажать Play

## Управление

WASD - движение, Left Shift - ускорение, Space - прыжок
Мышь - обзор, Escape - освободить курсор, левая кнопка мыши - захватить его снова

## Сцена

Пол размером 20 на 20, четыре стены и семь препятствий
Оранжевые ящики используют общий префаб PF_Obstacle
Три легких ящика имеют массу 2, тяжелый - 20, еще один ящик настроен как kinematic
Два препятствия статические, без Rigidbody
PlayerSpawner создает персонажа в PlayerSpawnPoint
При падении ниже Y = -8 персонаж возвращается к месту появления

## Исходники

Пять основных компонентов Player взяты из материалов преподавателя
PlayerFallRespawner добавлен отдельно для возврата после падения
ResetMotion и ResetLook сбрасывают движение и наклон камеры при возврате
Код построения сцены и получения снимков находится в Assets/_Project/Editor
Готовая сцена уже сохранена, повторно запускать ArenaBuilder не нужно

## Проверки

Window > General > Test Runner > PlayMode > Run All
Десять тестов проверяют создание персонажа, ходьбу и ускорение, диагональный ввод,
прыжок, стены, легкие и тяжелые ящики, падение, обзор и освобождение курсора
Тесты используют виртуальные устройства Input System и шаг времени 1/60 секунды
